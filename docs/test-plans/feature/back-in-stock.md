## Notes

- Privacy / email-collection and no-account rows ordered first (IDs 1–3).
- Assert against the feature doc and OpenAPI even where implementation is weaker (email format, `already_subscribed`, stock-0 badge copy, badge placement); mismatches are findings, not softened expectations.
- CSS-only files (`NotifyForm.module.css`, `StockBadge.module.css`) and `docs/features/back-in-stock.md` have no separate test rows.
- OpenAPI documents 409 `already_subscribed` and “full address” rules; API schema checks belong with rows 1–3 on every affected response.

## Assumed — ask

| Topic | Why |
