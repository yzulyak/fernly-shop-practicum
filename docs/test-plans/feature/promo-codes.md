# Test plan: feature/promo-codes

## Summary

Adds promo codes to the cart: `POST`/`DELETE /api/cart/promo`, cart and order fields `discount` and `promoCode`, store logic for percent and free-shipping codes, a `PromoCodeInput` under the cart order summary (slot), and discount lines on cart, checkout, and order summaries.
