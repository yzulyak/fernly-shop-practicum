# Test plan: feature/plant-reviews

Customers can read and write reviews on a plant’s page. This branch adds a reviews API (`GET`/`POST` `/api/plants/{plantId}/reviews`, `DELETE` `/api/reviews/{reviewId}`), seed reviews, and a plant-page Reviews slot with list, average, sign-in-gated form, and keyboard star rating.

Sources: `docs/features/plant-reviews.md`, OpenAPI registrations in `api/src/features/plant-reviews.ts`.

## Notes

- Money/privacy/sign-in rows ordered first (IDs 1–3, 6 guest gating).
- No delete control appears in the UI diff; ownership delete is covered at API level (ID 2) until a UI affordance exists — **assumed — ask** if a delete button was intended on the author’s own review.
- Average rounding and post-list refresh are asserted from the feature doc even if implementation differs; failures become findings, not softened expectations.
- CSS-only files (`Reviews.module.css`, `StarRatingInput.module.css`) and `docs/features/plant-reviews.md` have no separate test rows.
